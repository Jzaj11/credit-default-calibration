# credit-default-calibration
Projekt analizy ryzyka niewypłacalności posiadaczy kart kredytowych z wykorzystaniem uczenia maszynowego. Porównanie modeli klasyfikacyjnych, ocena jakości predykcji oraz kalibracja prawdopodobieństw niewypłacalności.

1. Utworzenie środowsika wirutalnego
py -3.12 -m venv .venv

2. Instalacja bibliotek z requirements.txt
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
